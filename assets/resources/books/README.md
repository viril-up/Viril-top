# Книги для Viril Top

Добавляй сюда PDF-файлы книг, на распространение которых у тебя есть права или разрешение.

После загрузки книги добавь объект в `assets/resources/catalog/books.json`:

```json
[
  {
    "id": "book-001",
    "title": "Название книги",
    "author": "Имя автора",
    "description": "Краткое описание книги в 2–4 предложениях.",
    "genre": "Психология",
    "cover": "assets/resources/book_covers/book-001.jpg",
    "file": "assets/resources/books/book-001.pdf"
  }
]
```

- `id` — уникальный идентификатор, не меняй его после публикации: по нему сохраняется прогресс чтения.
- `cover` — путь к обложке из папки `book_covers`.
- `file` — путь к PDF из этой папки.

Новые книги и обложки попадут в приложение после следующей сборки и публикации.
