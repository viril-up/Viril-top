# Видеотека Viril Top

Короткие видео будут добавляться в эту папку. Для каждого ролика добавляй запись в `assets/resources/catalog/videos.json` со следующими полями:

- `id` — постоянный уникальный ID.
- `title` — название ролика.
- `description` — короткое описание пользы или идеи.
- `video` — путь к MP4-файлу.
- `thumbnail` — путь к обложке.
- `topic` — тема (например, психология, мышление, наука).
- `duration` — длительность для отображения.

Сейчас создана структура каталога и экран видеотеки; полноценный видеоплеер и загрузка роликов в каталог будут следующим этапом.
