# Описания книг

Здесь можно хранить отдельные текстовые описания книг в формате TXT или Markdown.

В `assets/resources/catalog/books.json` используй поле `descriptionFile`, например:

`"descriptionFile": "assets/resources/book_descriptions/book-001.txt"`

Если `descriptionFile` не указан, приложение использует обычное поле `description` из каталога.
