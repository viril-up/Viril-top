# Эмблемы глобальных лиг Viril Top

Загружай изображения прямо в эту папку `assets/leagues/`. Для каждой лиги используй точное имя `league-01.png` … `league-60.png` (две цифры в номере). Формат — PNG, квадратное изображение, желательно 1024×1024 с прозрачным фоном.

Порядок файлов соответствует порядку лиг в приложении:
- 01–12 — I эпоха «Становление»
- 13–28 — II эпоха «Превосходство»
- 29–38 — III эпоха «Возвышение»
- 39–47 — IV эпоха «Познание»
- 48–60 — V эпоха «Трансцендентность»

Пример: эмблема Железной лиги — `assets/leagues/league-01.png`, Омниверсальной — `assets/leagues/league-60.png`.

Если файл ещё не загружен, приложение автоматически показывает встроенную иконку-заглушку. Папка уже подключена в `pubspec.yaml`.
