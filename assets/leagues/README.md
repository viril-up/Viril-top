# Изображения глобальных лиг

Здесь будут храниться изображения 60 лиг Viril Top. Используй имена файлов league-01.png … league-60.png по порядку, в соответствии со списком в lib/features/profile/data/global_league_data.dart.

Рекомендуемый размер: квадрат 1024×1024. Поддерживаемый формат для будущего подключения: PNG или JPG.
