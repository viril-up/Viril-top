# Profile cover

Помести сюда изображение для верхней обложки профиля и назови файл **cover.jpg**.

Рекомендуемый формат: JPG или PNG, горизонтальное изображение 16:9, не менее 1200×675 px.
После добавления файла Flutter подхватит его как `assets/profile_cover/cover.jpg`.
Пока изображения нет, профиль автоматически показывает тёмный градиент.
